============================================================================
NOTE — FFmpeg (a GPLv3 build: distribution is blocked only for a package
that enables the Media, Video or FaceTracking module)
============================================================================
The FFmpeg DLLs vendored in this repository were built with
`--enable-gpl --enable-version3` — they are a GPLv3 build. Distributing an
application dynamically linked against a GPLv3 FFmpeg places the WHOLE
application under GPLv3 obligations.

Only the Media, Video and FaceTracking engine modules use FFmpeg. A package
that turns all three off in game.json's "package"."modules" (the default
game.json does) links none of them and carries no FFmpeg DLL, and this note
does not restrict its distribution: props/Engine.App.props copies the DLLs only
while a build links Media or Video, CMake/CPack ships only the
DLLs the exe imports, and tools/package_audit.py fails a package that
carries a GPL DLL without a module that needs it.

A package that enables Media, Video or FaceTracking carries the GPLv3 DLLs
(its audit warns "CARRIES GPL"). Its distribution is BLOCKED until the DLLs
are replaced with an LGPL-v2.1+ build of FFmpeg (built WITHOUT
--enable-gpl) and this entry is updated to "FFmpeg — LGPL v2.1+".

The avfilter and avdevice DLLs, which nothing imports, are no longer in the
repository. This is decision D-1' of docs\reviews\ENGINE_REVIEW_2026-10-25.md
(its option (b), with the avfilter / avdevice part of (c)); it replaces
Top-15 #1 of docs\reviews\ENGINE_REVIEW_2026-08.md.
